## Project submission

Space Apps requests a final-project link and a project-demo link. The demo can be a video of up to 30 seconds or a slide deck of up to seven slides. The project's 20-second video fits the video duration requirement. The [Space Apps hosting clarification](https://github.com/nasa/spaceapps/discussions/1991) describes these formats and reviewer access.

Reviewers need links that open without an access request. Check the final project and demo URLs in a signed-out browser before submitting them. The [2026 submission guidance](https://github.com/nasa/spaceapps/discussions/1973) also covers the project description, data attribution, and disclosure of tools used. Use the official project page to complete submission.
